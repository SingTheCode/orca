Orca → Oh My DevX 이름 변경

2026-10-19 · 범위: 사용자에게 보이는 이름만 (선택: "보이는 이름만")

앱 이름은 Oh My DevX, 짧은 이름이 필요한 곳(CLI 명령, 설치 파일명, 번들 ID)은 omdx로 바꿨습니다. 소스 파일명, 변수·함수명, 환경변수 ORCA_*, 패키지 @orca/*, 데이터 폴더, orca:// 링크는 그대로 두어 upstream 변경을 계속 merge할 수 있게 했습니다.

일부러 그대로 둔 것

항목이유
데이터 폴더 ~/Library/Application Support/orcaCLI·daemon이 이 경로를 고정으로 찾습니다. 앱 이름이 바뀌면 Electron 기본 경로도 바뀌므로, 패키지 빌드에서 이 폴더를 명시적으로 고정했습니다(configure-process.ts, Windows는 windows-app-data-path.ts).
키체인 항목 "orca Safe Storage", "Orca Dev Safe Storage"저장된 토큰을 암호화한 키입니다. 이름이 바뀌면 기존 Jira 토큰 등을 복호화할 수 없습니다. package.json name orca와 dev 앱 이름 Orca Dev를 유지했습니다.
orca:// 링크, ~/.orca, ORCA_*, @orca/*내부 계약·데이터 경로. 바꾸면 upstream merge가 사실상 불가능해집니다.
Jira 요청 User-Agent OrcaJira XSRF 검사가 브라우저가 아닌 UA에 의존해 바꾸지 않았습니다.
TERM_PROGRAM=Orca터미널 도구들이 이 값으로 기능을 판단합니다.
'Orca server ready', X-Orca-* 헤더, "Managed by Orca" 표시스크립트나 다른 프로그램이 이 문자열을 찾습니다.
번들 스킬 이름 orca-cli 등사용자가 이름으로 설치하는 식별자. 본문 안내만 omdx로 바꿨습니다.
외부 주소 (github.com/stablyai, onorca.dev)실제 주소입니다.

호환성

  • CLI 이름을 검사하는 곳은 새 이름(omdx*)과 이전 이름(orca*)을 모두 받습니다. 이미 설치된 orca 명령이나 이전 버전 터미널에서 온 요청도 동작합니다.
  • macOS CLI 런처는 Oh My DevX.app을 먼저 찾고 없으면 Orca.app으로 대체합니다. Linux·Windows 런처도 같은 방식입니다.
  • Linux 설치 스크립트는 새 /usr/bin/omdx-ide를 만들고, 이전 /usr/bin/orca-ide는 우리 설치 폴더를 가리킬 때만 정리합니다.
기존 Orca와 함께 쓰지 마세요. 데이터 폴더와 키체인 키를 그대로 쓰기 때문에 upstream Orca와 프로필을 공유합니다. Oh My DevX로 옮길 때는 기존 Orca를 종료하고 지운 뒤 설치하세요.

남은 일

  • Windows CLI 런처(Rust, native/windows-cli-launcher)는 수정했지만 이 Mac에서 컴파일해 보지 않았습니다. Windows 빌드에서 확인이 필요합니다.
  • 앱 아이콘 이미지 자체는 바꾸지 않았습니다(이름만 변경).
  • 서명·공증 전이라 배포용 빌드는 아직 만들지 않았습니다.
